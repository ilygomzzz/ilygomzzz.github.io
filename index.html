Tag-Me Banco + tienda · trabajo en equipo

Código abierto · en equipo

Dos backends Spring Boot que se hablan por HTTP: una tienda online que cobra con tarjeta contra una API bancaria propia, con sus frontends en Angular.

Reto

Separar el dominio de la infraestructura para poder cambiar la base de datos o el cliente HTTP sin tocar las reglas de negocio, y probar el pago sin depender del banco real.

Solución

  • Capas controller · usecase · domain · persistence, con repositorios como interfaces del dominio.
  • Autenticación con JWT, contraseñas con hash (password4j) y validación de entrada.
  • Migraciones con Flyway y tests de integración con Testcontainers (MariaDB).
  • Módulo de integración propio en la tienda para pagos y cliente HTTP, aislado y testeable.
