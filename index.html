Proyectos

Tag-Me Banco + tienda · en equipo

GitHub ↗

Dos backends Spring Boot que se hablan por HTTP: una tienda online que cobra con tarjeta contra una API bancaria propia, con sus frontends en Angular. Mi parte fue sobre todo el backend.

Reto

Cada backend en capas con el dominio en el centro, la persistencia y el cliente HTTP detrás de interfaces, y poder probar el pago sin el banco real.

Solución

  • Banco: controller · usecase · domain · persistence, con casos de uso para pago con tarjeta y transferencia, JWT y validación de IBAN.
  • Tienda: controller · domain · persistence y un módulo integration (cliente HTTP y pago contra el banco); sesiones con token Bearer en base de datos.
  • En ambos: repositorios como interfaces del dominio, contraseñas con hash (password4j) y Bean Validation.
  • Flyway, tests de DAOs con Testcontainers (MariaDB) y el pago de la tienda probado con mocks.

IA, con correa corta

Aules Digest Agentes con Claude Code · código privado

Un sistema que me organiza el curso con agentes de IA. Claude escribe, pero no hace merge de lo suyo ni entrega mis tareas.

Qué hace

  • Resumen diario al móvil de entregas y fechas, redactado con Claude a partir de la API de Moodle, y tareas en Google Calendar.
  • Prepara el entorno de cada tarea (repo, material, enunciado) y genera apuntes con tarjetas Anki.
  • Corre solo con un temporizador de systemd.

Cómo lo controlo

  • Especificaciones primero: cada tarea lleva un brief y un checklist de aceptación verificable.
  • Lo determinista antes que el modelo: los scripts comprueban lo comprobable y un segundo agente validador, independiente, contrasta el resto.
  • Todo cambio va por pull request y la IA nunca hace push a main. Credenciales solo en .env y el texto de la plataforma se trata como no fiable.
